# Zombie Survival Lab

Projeto de estudo em Lua para Roblox Studio.

## Objetivo
Criar um protótipo local e autorizado para testar uma interface de sobrevivência, controles de movimento e mecânicas de combate contra NPCs de teste.

## Estrutura
- `README.md`: descrição do projeto.
- `main.lua`: protótipo de interface e controles para ambiente de teste.

## Uso
Abra o Roblox Studio, crie uma experiência de teste sua e adicione os scripts apropriados no local indicado. Este projeto não é um exploit para jogos públicos de terceiros.
