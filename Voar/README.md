# FLY CONTROL — protótipo de voo autorizado

Este diretório contém um protótipo de painel e lógica de voo para um ambiente de teste que você controla. Não é um exploit para jogos públicos de terceiros.

## Arquivo
- `fly.lua`: LocalScript para um jogo de teste próprio, com painel arrastável e botão ligar/desligar.

## Uso
Coloque `fly.lua` como LocalScript em `StarterPlayer > StarterPlayerScripts` no seu próprio projeto Roblox Studio. O botão liga/desliga o voo usando as teclas WASD e Espaço/Shift.
